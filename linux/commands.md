# Linux Command Practice

I am practicing basic Linux commands as part of my DevOps learning journey.

| Command | Purpose |
|---|---|
| `pwd` | Shows the current working directory |
| `ls` | Lists files and directories |
| `cd` | Changes the current directory |
| `mkdir` | Creates a directory |
| `touch` | Creates a file |
| `cat` | Displays file contents |
| `cp` | Copies files or directories |
| `mv` | Moves or renames files |
| `rm` | Removes files or directories |
| `chmod` | Changes file permissions |
| `df -h` | Shows disk space usage |
| `du -sh` | Shows the size of a directory |

## Practice

I created a local `devops-practice` directory and practiced creating,
viewing and managing files using the terminal.
