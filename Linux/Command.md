# Linux Basics

I am learning basic Linux commands used in DevOps and cloud environments.

## Basic Commands

| Command | Purpose                     |
| ------- | --------------------------- |
| `pwd`   | Shows current directory     |
| `ls`    | Lists files and folders     |
| `cd`    | Changes directory           |
| `mkdir` | Creates a folder            |
| `touch` | Creates a file              |
| `cp`    | Copies files                |
| `mv`    | Moves or renames files      |
| `rm`    | Removes files               |
| `chmod` | Changes file permissions    |
| `ps`    | Shows running processes     |
| `df`    | Shows disk space            |
| `du`    | Shows file/folder size      |
| `ping`  | Checks network connectivity |

## SSH

SSH allows us to securely connect to a remote server.

```bash
ssh username@server-ip
```

## Why Linux is important in DevOps

Linux is commonly used for servers and cloud infrastructure. DevOps engineers use the Linux command line to manage files, permissions, processes, networking and remote servers.
