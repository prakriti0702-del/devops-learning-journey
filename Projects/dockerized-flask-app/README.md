# Dockerized Flask Application

## Project Overview

This project demonstrates the basic process of packaging a simple Python Flask application into a Docker container.

## Objective

* Create a simple web application
* Understand the application structure
* Create a Dockerfile
* Build a Docker image
* Run the application inside a container
* Understand how Docker can support consistent application deployment

## Technologies

* Python
* Flask
* Docker
* Git & GitHub

## Basic Workflow

```text
Flask Application
       ↓
   Dockerfile
       ↓
 Docker Image
       ↓
 Docker Container
       ↓
 Web Application
```

## What I Learned

* Basic Flask application structure
* Docker images and containers
* Dockerfile fundamentals
* Basic Docker commands
* How containerization can be used in DevOps workflows
