# Linux Server Practice

This project contains basic Linux commands and system checks practiced locally as part of my DevOps learning journey.

## What I Practiced

* Navigating directories using `pwd`, `ls`, and `cd`
* Creating and managing files
* File permissions using `chmod`
* Checking disk usage using `df`
* Viewing running processes using `ps`
* Checking system information using `uname`
* Basic network information using `ifconfig`

## Hands-on Script

The `commands.sh` script automates several basic system checks:

1. Current working directory
2. Files and folders
3. System information
4. Disk usage
5. Running processes
6. Network information

## DevOps Relevance

Linux is widely used for cloud servers and DevOps environments. These commands help with basic server administration and troubleshooting.
