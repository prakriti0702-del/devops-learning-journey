# Git Workflow Practice

This project documents my hands-on practice with Git and GitHub as part of my DevOps learning journey.

## Git Workflow Practiced

```text
Working Directory
       ↓
   git add
       ↓
   Staging Area
       ↓
  git commit
       ↓
 Local Repository
       ↓
   git push
       ↓
     GitHub
```

## Commands Practiced

* `git status` — check repository status
* `git add` — stage changes
* `git commit` — save changes locally
* `git push` — upload changes to GitHub
* `git pull` — get changes from GitHub
* `git log` — view commit history

## What I Learned

I practiced creating changes, tracking them with Git, committing them, synchronizing my local repository with GitHub, and resolving a push synchronization issue using:

```bash
git pull --rebase origin main
git push origin main
```

## DevOps Relevance

Git is an essential part of modern DevOps workflows. Source code and configuration changes can be tracked, reviewed, and integrated with CI/CD pipelines.
